# shoestore — решение mdk1101

это полноценный стек из бэкенда на fastapi, веб-морды на react и десктопного приложения через tauri. всё упаковано, типизировано и разбито на модули.

## структура

проект разбит на три основные части, чтобы не валить всё в одну кучу:

- **solution/backend** — питоновский сервак на fastapi. тянет базу на sqlite, рулит авторизацией и раздает данные.
- **solution/web** — фронтенд на react 19. тут живет вся логика каталога, фильтров и личного кабинета.
- **solution/desktop** — то же самое что и веб, но завернуто в tauri для работы на компе как отдельное приложение.
- **scratch** — папка с моими сервисными скриптами для анализа и рефакторинга кода.

## технологии

### бэкенд
- **python 3.11+**
- **fastapi** — для быстрых эндпоинтов
- **sqlalchemy** — чтобы общаться с базой без боли
- **python-jose** — для jwt токенов
- **sqlite** — простая и быстрая база в файле

### фронтенд (веб и десктоп)
- **react 19** + **typescript** — строгая типизация везде
- **vite** — быстрый запуск и сборка
- **tailwind css** — для стилей без лишних файлов
- **shadcn/ui** — готовые компоненты (кнопки, карточки, модалки)
- **lucide-react** — набор иконок

## запуск

### бэкенд
заходим в папку бэка, ставим зависимости и запускаем:

```bash
cd solution/backend
python -m venv .venv
source .venv/bin/activate  # на винде .venv\Scripts\activate
pip install -r requirements.txt # или вручную основные либы
python run.py
```
после этого апи будет висеть на http://127.0.0.1:8000

### веб
тут стандартно через npm:

```bash
cd solution/web
npm install
npm run dev
```

### десктоп
если есть установленный rust, можно запустить tauri:

```bash
cd solution/desktop
npm install
npm run tauri dev
```

## что внутри (фичи)

- **каталог товаров**: поиск по описанию, фильтр по брендам, макс. цене. есть переключатели для товаров со скидками и тех, что в наличии.
- **авторизация**: полноценная регистрация и вход. сессия живет в локалсторедже, токен подкладывается в заголовки запросов автоматически.
- **роли**: есть админы, менеджеры и обычные клиенты. админы могут менять статусы заказов.
- **заказы**: история покупок, создание новых заказов. если нажать «заказать» без логина, приложение запомнит выбор и предложит оформить всё сразу после входа.
- **архитектура**: фронт разбит на слои (api, types, lib, components, pages). никакой каши в одном файле.
- **визуал**: темная/светлая темы, скелетоны на загрузке, плавные анимации появления карточек.

## особенности стиля
код прокомментирован максимально подробно в разговорном стиле. каждый важный кусок логики объяснен простыми словами, чтобы было понятно не только компьютеру, но и человеку.
